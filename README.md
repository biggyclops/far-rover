# far-rover
Far Rover demo: pick sensors, write rules, and watch a rover explore on its own.

The live operate board is an orbital HiRISE view. Imagery credits are in `CREDITS.md`.

The v0.8 hands-on base prototype lives at `/v08/` (first full playable: scout expedition + land-crew goal). It does not change this demo. Scout expeditions import `simulation.js` through `v08/engine.js` — never a fork.
