# far-rover
Far Rover demo: pick sensors, write rules, and watch a rover explore on its own.

The live operate board is an orbital HiRISE view. Imagery credits are in `CREDITS.md`.

The v0.8 hands-on base prototype lives at `/v08/` (Milestone 2: tunnels). It does not change this demo. The scout expedition will import `simulation.js` through `v08/engine.js`.
